# AK World - What Is My IP

A modern IP lookup tool built with Next.js.

## Features

- IPv4 & IPv6 Detection
- Browser Information
- Operating System
- Device Type
- ISP
- ASN
- Organization
- Timezone
- Language
- Screen Resolution
- Copy IP
- Share
- Refresh

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
